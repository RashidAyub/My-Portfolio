# Rashid Ayub - Personal Portfolio

A premium, modern, fully responsive personal portfolio website built with HTML5, CSS3, JavaScript, Bootstrap 5, GSAP, and Three.js.

## Live Demo

Deploy on [Vercel](https://vercel.com) for a live preview.

## Features

- Premium dark/light mode theme
- Smooth Lenis scrolling
- GSAP scroll animations
- Particle background effect
- Three.js floating 3D objects
- Custom animated cursor
- Magnetic button effects
- Animated typing effect
- Counter animations
- Scroll progress indicator
- Premium MIR 3D loader with glassmorphism
- Developer dashboard (`dashboard.html`)
- Glassmorphism UI
- Portfolio filter gallery
- Testimonial slider
- Timeline resume section
- Fully responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Font Awesome 6
- Google Fonts (Poppins)
- GSAP + ScrollTrigger
- AOS (Animate On Scroll)
- Lenis Smooth Scroll
- Three.js
- Typed.js

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/RashidAyub/My-Portfolio.git
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   npx serve .
   ```

## Customization

All personal information is easily editable in `index.html`:

- **Profile Photo**: Replace `images/profile.png` with your own photo
- **Personal Info**: Update the About section details (birthday, phone, email, etc.)
- **Social Links**: Update GitHub, LinkedIn, Facebook, Instagram URLs
- **Portfolio Projects**: Add your own projects in the Portfolio section
- **Resume**: Update education and experience timeline
- **Contact Info**: Update phone, email, and address

## Deployment

### Vercel
1. Push to GitHub
2. Import project on [vercel.com](https://vercel.com)
3. Deploy automatically

### GitHub Pages
Enable GitHub Pages in repository settings, set source to `main` branch.
